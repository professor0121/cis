Tips for the AI voice round:

Speak slowly and clearly. Don’t memorise word for word, because it should sound natural.
Answer in 30-60 seconds per question. Don’t ramble.
Give one example for every claim, like “I built X using Y”.
Sit somewhere quiet with good internet and a headset, and look at the camera.
Expect follow-ups such as “Why CIS?”, “Tell me about a project”, “What is OOPs?” and “Why should we hire you?”. Prepare short answers for each.

Section	Topics  
Aptitude / Logical	Percentage, ratio, time-work, speed-distance, series, puzzles, seating arrangement, blood relations, coding-decoding
Verbal English	Grammar, reading comprehension, sentence correction, synonyms/antonyms

C / C++ / Python / Java basics	Output-prediction MCQs, pointers, arrays, strings, loops
Coding (possible)	1-2 easy-to-medium problems: arrays, strings, patterns, basic sorting/searching
Web basics	HTML, CSS, JS fundamentals

Priority order for revision: OOPs, then SQL queries, then aptitude practice, then C/C++ output questions, then easy coding problems.

Since your stack is JS-first and CIS asks for OOPs, C/C++ and Database, spend extra time on OOPs theory and SQL joins. Those are likely your weaker spots compared to React/Node.
